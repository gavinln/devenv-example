# Flask example

## Run the imgapp Flask application

imgapp is a [Flask][200] application

[200]: https://github.com/pallets/flask

1. Run imgapp

```sh
make imgapp
```

2. Open a web browser at `http://127.0.0.1:5000/`

3. View an image at `http://127.0.0.1:5000/image`

4. Build the app

```sh
poetry build
```

5. View the build files

```sh
ls dist/
```
